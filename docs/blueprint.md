# **App Name**: Niki's Charms

## Core Features:

- Product Catalog & Detail Pages: Browse and view handmade items (bracelets, keychains, photocards) with high-quality images, detailed descriptions, prices, personalization options, and category/filter capabilities.
- Personalized Shopping Cart ('Pouch'): Add items to a 'pouch', manage quantities, view personalizations, and review a summary before a minimal checkout process.
- Dynamic Homepage Display: Features a full-width looping hero video, horizontal-scrolling bestsellers, an embedded Instagram shop feed, and Niki's handwritten welcome note to capture the brand's aesthetic.
- Charm Diary Scrollytelling: Explore the brand's unique blog/journal in a vertical scrollytelling format with polaroid-style tiles, offering tutorials, inspiration, and Niki's personal playlists.
- Aesthetic Site Interactivity: Implements interactive elements like a sun/moon mood toggle for theme switching, a custom thread-knotting loading animation, and a heart/star cursor trail for 'Add to Pouch' buttons.
- Product Content Management: A system to upload, edit, and organize product listings, including images, pricing, inventory, and customization fields.
- AI-powered Gift Note Tool: An AI tool that suggests short, whimsical, or sentimental messages for gift tags or personalized notes, complementing the product's customization options.

## Style Guidelines:

- Primary color: Dusty Rose (#E8B4B8). This soft, warm pink encapsulates the brand's whimsical and ethereal mood.
- Background color: Off-white/cream (#FEF7E8). This gentle, creamy base creates a dreamy and cozy atmosphere.
- Accent color: Honey Gold (#E8C468). A warm, inviting gold for highlighting calls to action and interactive elements, adding a touch of vintage charm.
- Headlines will use 'Playfair Display' (serif, elegant but playful). Body text will use 'DM Sans' (sans-serif, clean and readable). Accent text for notes and charm descriptions will use 'Caveat' (handwritten style). Note: currently only Google Fonts are supported.
- Utilize celestial motifs like moon icons for bestsellers, star/heart trails for cursor effects, and subtle badges (e.g., '✨ handmade') to reinforce the sentimental and handmade nature of the brand.
- A mobile-first, responsive design featuring a full-width hero video, horizontally-scrolling bestseller rows, masonry product grids, left-aligned gallery carousels on product pages, and a unique vertical scrollytelling layout for 'The Charm Diary'.
- Subtle animations include pulsing effects for 'Shop Now' buttons, product image hover zooms, a thread-knotting loading screen, gentle shaking for low-stock warnings, and interactive cursor trails on key interaction points.
